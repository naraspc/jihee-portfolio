## 프로젝트 소개

여자친구가 Illustrator로 제작한 포트폴리오를 웹사이트로 구현하는 중입니다.

현재는 개발환경과 기본 구조를 만들어 둔 상태이고, 포트폴리오 PDF를 전달받은 뒤 본격적으로 작업할 예정입니다.

## 개발 방향

* 원본 포트폴리오의 색상과 분위기 유지
* 데스크톱과 모바일 반응형 지원
* 프로젝트별 이미지와 설명 구성

* PDF 다운로드 기능 제공

## 실행 방법

```bash
git clone https://github.com/naraspc/girlfriend-portfolio.git
cd girlfriend-portfolio
npm install
npm run dev
```

개발 서버는 기본적으로 아래 주소에서 실행됩니다.

```text
http://localhost:5173
```
